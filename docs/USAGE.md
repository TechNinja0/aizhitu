# AI智图 1.6 使用指南

## 启动

分享包解压后，在包含 package.json 的目录执行：

```sh
node bin/zhitu.mjs
```

需要 Node.js 22.22+。首次自动安装依赖和 Chromium，需要联网；Mac 也可双击 `start.command`。终端保持运行，按 Ctrl+C 停止。默认打开 `http://127.0.0.1:4317`，端口冲突用 `node bin/zhitu.mjs --port 4318`。

源码开发执行 `npm ci`、`npm run setup`、`npm run dev`。修改源码后运行生产版前先 `npm run build`。

## 共享文件库与局域网

主页为文件库，新建空白或模板图稿后，首次修改内容或名称才自动保存到“全部文件”，默认私有；未修改直接返回不留下文件。也可主动点击“保存到文件库”保留未经修改的模板或空白，导入文件直接入库。已有服务器草稿合并到“全部文件”，不再需要发布。通过分享窗口选择“指定成员”或“所有成员”并保存权限后，对方才可访问；复制链接不会自动授权。已授权图稿默认只读，取得编辑权后约每 2 秒自动保存与同步。文件库支持创建人显示、我拥有的筛选、图稿名称编辑、单个或批量移入回收站和恢复。

局域网启动：`node bin/zhitu.mjs --lan-host <服务器内网IP> --port 4317 --editor-port 4318`。成员使用固定账号密码登录，可记住登录 30 天；旧浏览器先补设账号；服务电脑通过本机地址进入管理界面。详细身份、共享操作、版本恢复、断线处理与备份见 [局域网共享指南](LAN_WORKSPACE.md)。

`/local` 是本地临时画布，可从示例开始，或恢复旧浏览器草稿，再点“保存到文件库”。旧草稿不会自动上传。

## 创建和编辑图稿

- 文件库列表上方左侧提供文件分类、**我拥有的**筛选和搜索；右侧提供 **新建图稿**、**导入图稿** 和 **本地临时画布**。新图稿名称在新建浮窗中填写。
- 顶部账号区、工具栏、表头和底部分页保持可见，只有文件列表滚动。默认每页 10 条，可选 20／50／100 条，当前浏览器会记住选择。搜索在服务器端覆盖全部有权限访问的文件；翻页、筛选或改变每页数量会清空勾选，批量操作仅针对本页。删除末页全部文件后自动回到有效页。
- 点击 **新建**（文件库中为 **新建图稿**）打开模板浮窗，可选空白画布、36 个内置模板或「我的模板」。按系统架构、业务流程、数据设计、组织与规划筛选，也可搜索关键词。内置模板包括 24 个进阶模板，支持按进阶/基础筛选。系统架构分类有 24 个模板，覆盖 APP 分层、组件化、离线同步、Flutter、BFF、DDD、微服务、事件驱动、CQRS、SaaS、Serverless、Kubernetes、跨地域容灾、IoT、RAG、可观测平台、湖仓和 C4；可搜索 APP、服务架构、云部署、数据架构等关键词。
- 点击模板卡片查看预览，使用 **放大预览** 查看完整图；填写名称后点击 **使用此模板**，节点、文字、连线会直接绘制在新画布中并可继续编辑。选择 **空白画布 → 创建空白画布** 可从零开始。浏览或取消不会修改当前图，确认创建时如有未保存修改会提示处理。
- 已创建的空白草稿也可点击左侧图形栏底部 **选择模板**，预览后 **应用到当前草稿**。保留当前文件名与链接，支持一步撤销；共享草稿确认应用时自动申请编辑权，若其他人正在编辑会提示，且不会覆盖已有内容。
- 模板及预览内置，无需联网；详情中的参考链接指向公开图式资料。模板依据常见结构重新绘制，参考来源见 [模板说明](../packages/diagram-templates/README.md)。本地模板新建后需保存；从文件库或共享图稿新建模板稿时，首次修改后才自动保存为独立私有文件，未经修改返回不保存；需要协作时再设置分享权限。

- 用 **新建** 选择空白画布或模板，用 **打开** 导入支持范围内的单页 `.drawio` 或 XML。需要体验识别核对时，可在 **识别核对** 面板点击 **体验核对示例**。
- 左侧拖入图形；双击编辑文字；拖动节点、连接端点或折点。选中对象后右侧属性区可改文字、尺寸、线条、组合和层级。
- 普通鼠标滚轮滚动画布；按住 Command 再滚轮，以鼠标位置为中心缩放（非 Mac 可用 Ctrl）。按住空格并按鼠标左键拖动可平移视图，松开空格退出；文字输入时空格仍正常输入。画布右下角 −/+、百分比和适应按钮控制视口，点击百分比恢复 100%；会话区滚轮只滚动消息。
- **查找对象** 按文字或 ID 定位；**一键美化** 只整理可安全拉直的连线，不移动节点。
- 批量样式、排列和候选应用都可用顶部撤销恢复；常规编辑保留 100 步撤销。

### 保存自己的图稿为模板

1. 打开有内容的图稿，点击工具栏 **保存为模板**。
2. 填写模板名称、分类与说明，核对自动生成的预览，点击 **保存到我的模板**。预览失败时可以重试，图稿不会被修改。
3. 在 **新建** 或空白草稿左下角 **选择模板 → 我的模板** 中复用。新建时生成独立图稿；应用到空白草稿时保留当前文件名和链接，并支持撤销。
4. 选中个人模板后可 **编辑信息**（名称、分类、说明）或 **删除模板**。删除需确认，不会删除已经创建的图稿。

个人模板是保存时图稿的独立快照，原图或副本的后续修改不会自动覆盖模板。每个身份最多 100 个模板，仅自己可见，存储在服务器数据目录的 `templates.sqlite` 中，重启仍保留。备份时与工作区数据库一起备份；正在运行的 SQLite 数据还可能包含 `-wal`、`-shm` 文件。

复杂图可在 **放大预览** 中使用 **放大 / 缩小 / 适应**，放大后滚动查看细节。

## 主题、颜色和快捷样式

**主题配色** 打开 10 套可视化主题，也可用选择主题下拉框。无选区时作用于全图；有选区时作用于所选对象及其组内内容。工具栏会明确显示范围。主题跳过锁定对象，不改变文字、位置、形状和关系。

选择对象后：

1. 选择颜色目标：填充、边框/连线或文字。
2. 点击现成色点直接应用；用颜色选择器或输入 `#RRGGBB` 后点 **用色**。填充和边框可点 **无色**。
3. 成功使用的颜色会进入 **最近** 快捷栏，最多 10 个、去重排序，在同一浏览器和地址中保留。
4. **复制样式** 从选中对象读取外观；再选目标点 **粘贴样式**，保留目标文字、形状、布局和连线。
5. **对齐与分布** 提供左/中/右、上/中/下对齐和水平/垂直等间距。对齐至少 2 个节点，等间距至少 3 个，须在同一容器中；锁定节点不参与。

## 在画布中与 AI 对话

1. 服务电脑上安装并登录 Codex/Qoder CLI；共享模式由管理员配置，成员共用服务器额度。
2. **设置 → AI 客户端** 中检测路径，保存后显式测试连接。未找到时填写可执行文件绝对路径，不填写 shell 命令。
3. 打开 **AI 会话**。输入框底部选 CLI；Codex 沿用本机模型，Qoder 可选 Auto 或指定模型。
4. 选择 **修改当前图**、**仅修改选区** 或 **重新生成整张图**。附图用回形针，也可粘贴或拖入 PNG/JPEG（单张 8 MiB 内）。
5. Enter 发送，Shift+Enter 换行。消息立即出现；执行区展示真实阶段、耗时和生成字符数。方形按钮可停止，失败/取消保留要求与附件。
6. 完成后点击 **预览候选**，立即打开大图窗口。可缩小、放大、适应；核对后点 **应用此候选**，或返回会话后点 **应用到画布**。

示例要求：

> 按截图重画成可编辑流程图，保留文字、连线方向和分组。不要把截图当作整张图片插入。

> 仅把所选“订单服务”改为“订单处理服务”，其余文字、布局、样式和关系保持不变。

> 在当前图增加缓存模块，连接到库存服务，保留其他对象和布局。

当前图稿、选区和附件在发送时交给所选客户端及其模型服务；网页内会话无需另外安装 Skill。外部 Skill 仍可按 [AI 接入说明](../packages/ai-support/INSTALL.md) 使用。

## 预览、冲突与候选保留

- 渲染时窗口显示“正在渲染”，失败显示具体错误并可 **重新预览**，不需要重新请求模型。
- 候选可随时 **下载候选 .drawio**；它可以单独打开编辑，适合保留长时间生成结果。
- 应用前自动保存原稿版本，整次应用可一步撤销。
- 缩放、选择对象和 XML 等价格式不使候选过期；编辑后撤销回相同内容也可继续应用。
- 如果等待期间改变了原稿，系统不会直接覆盖。可以保留当前图稿、下载候选单独使用，或在预览后明确确认强制覆盖当前画布；覆盖前自动备份，再次变化时需要重新确认。共享模式仍须持有编辑权，服务器版本冲突不能绕过。
- **比较 AI 候选** 可打开外部生成的同文档候选，预览并应用；属于不同 documentId 的文件只允许检查，须单独打开使用。

## 保存、草稿和版本

| 入口 | 用途 |
| --- | --- |
| 自动保存到服务器 | 持有编辑权时自动保存，状态栏显示保存结果；结束编辑或返回文件库时先保存再释放编辑权，其他页面自动更新 |
| 服务器版本 | 每份文档最近 50 个版本，恢复需要编辑权并生成新版本 |
| 下载副本 | 下载可继续编辑的 `.drawio` 到本机，不在文件库新建文件；保存位置由浏览器设置决定 |
| 保存到文件 | 支持 File System Access API 时授权写回；不支持时退回下载 |
| 恢复草稿 | 找回当前浏览器/站点里的未保存图稿；不是长期备份 |
| 版本记录 | 保存命名版本、下载和恢复；恢复前备份当前图稿，每图最多 20 版、全局约 40 MiB |
| 最近 AI 任务 | 刷新后接回仍在本地服务中的任务/候选，须打开内容一致的原稿；服务重启后无记录 |

共享文档在服务器 SQLite 中持久保存，浏览器缓存清理不会删除它。共享页的下载副本不会将未同步修改标记为服务器已保存。服务器完整备份见 [共享指南](LAN_WORKSPACE.md#数据位置与备份)。

本地文件写回会检测已知的外部文件修改和切图状态，但不提供跨程序文件锁。更换浏览器、端口或清理站点存储可能使本地草稿/版本/颜色不可见。关闭服务之前下载需要保留的图稿与 AI 候选。

## 核对与导出

**原图对照** 并排检查截图；**识别核对** 定位疑点并确认。相关文字或关系变化后重新待核对。结构校验不保证 AI 识别正确，需确认关键业务关系。

- PNG 支持 1/2/3 倍、边距与透明背景；SVG 保留矢量并内嵌图片；PDF 是单页整图。
- PNG/SVG 可导出选区，选择时包含需要的连线；PDF 当前导出整图。
- 整图 PNG/SVG 可选择嵌入可编辑源文件，分享时也会带上全部源图稿。普通截图不包含可编辑节点。
- 编辑选框、原图对照和核对界面不出现在导出结果中；导出不会将源图稿标记为已保存。

## 命令行与分享

```sh
node bin/diagram.mjs doctor --json
node bin/diagram.mjs validate --input fixtures/examples/flow.drawio --json
node bin/diagram.mjs render --input fixtures/examples/flow.drawio --format png --output output/flow.png --scale 2
```

render 支持 png/svg/pdf、`--margin`、`--background`，PNG/SVG 支持 `--selection id1,id2`。输出必须是新文件，CLI 不自动覆盖。完整参数看 `node bin/diagram.mjs --help`。

分发执行 `npm run package:local`，分享 `artifacts/ai-zhitu-local.tar.gz` 和 SHA-256 文件。接收者使用自己的 CLI 登录，不需要复制你的账号或设置。详细说明见 [LOCAL_AI.md](LOCAL_AI.md)。

## 故障排查

| 现象 | 处理 |
| --- | --- |
| 页面打不开 | 确认启动终端仍运行；打开终端打印的地址；端口冲突换 4318 |
| 修改后仍旧界面 | `npm run build` 后重启服务；保存图稿后刷新页面 |
| CLI 未找到/未登录 | 设置中检测或填写绝对路径，在终端完成对应 CLI 登录 |
| Codex 提示需要新版 | 在设置中选择已检测出的新版应用内 CLI，或自行升级；工作台不会修改全局安装 |
| 预览失败 | 看大图窗口错误并重试；可先下载候选，不用重新消耗 AI 额度 |
| 候选冲突 | 原稿确实变化时下载候选另开；或基于最新画布重发；编辑后撤销回原稿可再次应用 |
| AI 无输出或很慢 | 查看执行摘要与耗时，可停止重试/换模型；无输出 5 分钟或总计 20 分钟自动结束 |
| 修改选区失败 | 新增外部节点或跨选区结构变化改用“修改当前图” |
| 颜色按钮不可用 | 先选一个未锁定对象；填充不作用于单独连线 |
| 对齐提示容器不同 | 选择同一容器中的节点，不跨组直接排列 |
| 导入不支持 | 保留原文件，按照 profile 使用支持的基础图形；当前只支持单页 |
| 导出尺寸超限 | 降低倍率、使用选区或缩小内容范围 |
| Chromium 缺失 | 检查网络后运行 `npm run setup` |

当前验证范围见 [v1.1 验收报告](testing/V1_1_REPORT.md)。

### 设置页保存入口

AI 客户端设置的右下角为绿色「保存设置」按钮，固定在弹窗底栏；滚动配置内容时仍可见。底栏显示是否有未保存的更改。连接验证位于独立区域，修改后先保存，再测试 AI 连接。

指定成员按固定用户 ID 区分，同名用户不会自动继承权限。请核对登录名与身份编号；换浏览器后登录原账号即可恢复授权。本机管理员保留全部文件管理权。升级到 v1.4 时，旧文件默认收回分享，内容、版本与链接保留，需要创建者重新选择分享范围。

固定账号注册、旧身份补设、找回密码和本机管理员用户管理见 [账号指南](ACCOUNTS.md)。
