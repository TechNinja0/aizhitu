# v1.2.1 用户名入口验证

验证日期：2026-09-20；环境：macOS arm64、Node.js 22.22.0、Playwright Chromium。

## 交付行为

- 首次仅填写用户名，无密码或访问码；同一浏览器、同一地址记住随机身份。
- 同名新访问者获得不同身份；修改用户名保留身份 ID、文件归属并更新编辑租约名称。
- 有效旧会话跨升级保留身份，旧远程管理员转为成员，已失效会话不复活。身份跨一年模拟时间与服务重启仍有效。
- 网络连接失败时保留浏览器凭据，恢复后重新连接；只有明确的无效会话响应才清除凭据。
- 本机地址向服务电脑提供管理员入口，局域网网页不包含管理员 token。伪造 Host 的局域网连接也不会获得该 token。
- 编辑锁、自动保存与其他页面同步、历史版本、回收站保持原有机制；此次未实现多人同时实时编辑。
