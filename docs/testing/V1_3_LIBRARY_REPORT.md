# v1.3 草稿与文件库管理验证

日期：2026-09-20；环境：macOS arm64、Node.js 22.22.0、Playwright Chromium。

## 本次交付

- 新建、模板、导入强制创建服务器草稿；普通成员只访问自己的草稿，本机管理员可管理全部草稿。旧文件迁移后仍保持共享。
- 草稿自动保存，空闲时自动取得编辑权，返回文件库前保存；确认名称后发布到共享文件库，保持文档 ID、创建人和历史。
- 发布窗口打开时继续续约；模拟发布失败后可保留表单重试。
- 文件库支持创建人列、我创建的筛选、搜索、数量、列表重命名、单个及批量移入回收站、恢复。批量操作按权限、版本和锁全量检查，失败整批回滚。
- 草稿恢复回草稿区，共享文件恢复回共享文件库，无永久删除或自动清理。
- 管理员由服务电脑的本机入口决定；同名用户不会获得他人的身份或管理员权限。
