# 本地 AI 会话与分享

更新：2026-09-20。v1.2.1 支持局域网共享工作区；CLI 始终运行在服务电脑上，部署与身份规则见 [共享指南](LAN_WORKSPACE.md)。

## 配置与使用

1. 在电脑上安装并登录 Codex 或 Qoder CLI。工作台复用该客户端的账号、服务配置和额度，不存 API Key。
2. 页面右上角 **设置 → AI 客户端**。执行路径留空会从 PATH 和常见安装目录检测；未找到时填写可执行文件绝对路径，不填写 shell 命令或附加参数。macOS 检测会列出已安装应用中的备用 Codex 版本，可选择后保存。
3. 检测不会保存表单；请点击“保存设置”后再测试连接。关闭设置会丢弃未保存字段。设置默认客户端。Codex 始终沿用本机模型配置，不提供模型选择；Qoder 可选择 Auto、Qwen3.8-Max、Qwen3.8-Flash、Qwen3.7-Max、Qwen3.7-Plus、Kimi-K3、Kimi-K2.8-Preview、GLM-5.3。列表已用本机 Qoder CLI 1.1.42 的 `--list-models` 核实，实际访问受各自账号权限影响。
4. “检测”只执行 `--version`，不调用模型。“测试 AI 连接”会发起一次小请求，可能消耗客户端额度。未登录请在终端运行 `codex login` 或 `qodercli login`。
5. 打开 **AI 会话**，在输入框下方选择客户端、模型与修改范围，填写要求，可选择、粘贴或拖入一张 PNG/JPEG 截图。发送时采集最新未保存画布、选区及修订号。
6. 生成完成后核对差异，点击 **预览候选** 打开独立大图窗口，检查后点击 **应用此候选** 或返回会话点击 **应用到画布**。预览失败可以重试，候选始终可单独下载。应用前自动备份原稿，可从“版本记录”找回。一次应用可以一步撤销。生成过程不会直接改动画布或磁盘源文件。

“重新生成整张图”会在用户应用后替换当前画布内容，仍可撤销；需要独立文件时先新建图稿。仅修改选区模式会校验对象差异，拒绝修改选区之外的对象。首版选区模式不用于新增外部节点或跨选区重构，可改用“修改当前图”。

## 会话与缩放

- 点击箭头或 Enter 发送，Shift+Enter 换行；输入法选词的 Enter 不会误发。回形针上传，或粘贴/拖入截图。
- 发送后立即显示用户消息和附件名称。生成期间显示耗时、真实 CLI 阶段与已生成字符数；执行过程可展开查看，最终显示候选变更。方形停止按钮取消当前任务。
- 运行摘要来自 CLI 事件，不展示隐藏推理、原始日志或工具参数；不是模拟的“思考过程”。会话历史保留边界见下文。
- 画布区域普通鼠标滚轮滚动，Command/Ctrl + 滚轮缩放；工具栏有 − / +、百分比（点击恢复 100%）和“适应”。范围 10%～400%，不改变图稿内容或撤销历史。会话区滚轮仍滚动消息。

## 状态含义

| 状态 | 含义 |
| --- | --- |
| CLI 未安装 | 当前路径下没有可执行客户端 |
| CLI 可用 · AI 未验证 | 找到客户端，但尚未证明模型能响应 |
| AI 已连接 | 所选客户端和模型最近 15 分钟内成功响应；显示上次验证时间，不保证网络持续在线 |
| 连接待验证 | 上次验证已超过 15 分钟，或切换了模型 |
| 正在测试连接 / AI 生成中 / 校验候选中 | 当前任务所处阶段 |
| AI 连接异常 / 本地服务未连接 | 请求失败或无法连接工作台本地服务 |

工作台每 15 秒读取本地状态，不自动发模型探测请求。更改执行路径或默认模型后重置验证状态。

## 数据与限制

- 设置保存在 `~/.ai-zhitu/clients.json`，仅包含默认客户端、执行路径和模型名称。
- 单轮任务使用私有临时目录；结束、失败或取消后清理。候选在服务内存中保留最多 30 个，访问时清理超过一小时的任务。
- 会话、基线与候选保存到服务数据目录 `ai-history.sqlite`，按账号和图稿隔离；打开图稿自动恢复最近 12 轮上下文。“历史与候选”支持分页、命名、接回、删除和 7/30/90 天保留设置，默认 30 天；每账号最多 100 条和 128 MiB 逻辑负载，超过后清理最旧终态。截图二进制不保留，重试需重新上传。切换图稿会取消当前任务并读取对应历史；关闭侧栏不会取消。
- 取消或失败会保留当前网页内本轮要求和截图，便于重试；服务端结束后的截图仍按临时数据清理。
- 网页刷新或关闭不会立即终止已提交任务；服务仍按超时回收。停止本地服务会取消其所有 AI 任务。
- 一次只运行一个模型任务；连续 5 分钟无标准输出会终止；有持续输出的绘图任务最长 20 分钟（包括修复轮次）。图稿校验失败最多生成 3 次候选，可能额外消耗额度。
- 对话输入图稿上限 2 MiB；单张 PNG/JPEG 附件上限 8 MiB。一般文件打开上限保持原规格。
- 当前图稿、会话和附件会交给所选 CLI 及其模型服务；客户端的服务配置决定 AI 数据处理位置。编辑、校验与导出仍本地执行。
- Codex 使用 read-only 执行环境，仅要求返回 XML；Qoder 禁用内置工具、单次调用的 Hook 和外部 MCP 加载，仅返回 XML。工作台解析最终回答，校验通过后形成候选，不执行模型输出的 shell 命令。用户自行安装的 CLI 扩展和全局配置仍由该客户端管理。
- 采用固定参数数组和 `shell:false`，不启用 bypass permissions 或无沙箱参数。不读取或复制客户端密钥。
- CLI 原始事件和 stderr 不展示、不持久化；页面仅显示状态与受控错误提示。客户端自身日志策略由客户端配置决定。

## 查找对象与版本记录

“查找对象”按文字或对象 ID 搜索节点、连线，选择结果会定位到画布。

“版本记录”可保存带说明的当前版本、下载版本或恢复。恢复前再备份当前画布，恢复动作可一步撤销。每图最多 20 版，全局最多 40 MiB，超限清理最旧记录；版本保存在当前浏览器、当前地址中，不随启动包分享，也不替代磁盘源文件。

## 一条命令启动

解压分享包后，进入目录：

```sh
node bin/zhitu.mjs
```

要求本机有 Node.js 22.22+。首次自动安装项目依赖和 Chromium，需要联网；后续启动复用。启动成功后打开本机浏览器。Mac 也可双击 `start.command`；遇到系统限制可从终端运行上述命令。

```sh
node bin/zhitu.mjs --port 4318
node bin/zhitu.mjs --no-open
node bin/zhitu.mjs --help
```

终端保持运行，`Ctrl+C` 停止。安装为本地命令（可选）后可运行 `zhitu`；目前无需全局安装即可使用。

生成分享包：

```sh
npm run package:local
```

输出 `artifacts/ai-zhitu-local.tar.gz` 和对应 SHA-256 文件。打包采用明确清单，含源码、构建产物、编辑器与字体、文档和许可证，不含 `node_modules`、个人 CLI 配置、`~/.ai-zhitu`、测试输出或个人图稿。独立安装时同事使用各自的 CLI 登录与额度；连接同一局域网服务时共用该服务器的 CLI 与额度。不要复制发送者的账号文件。

## 后续 Mac 软件封装

当前交付为命令启动的本地应用，不是 `.app` 或 `.dmg`。架构可以继续封装为桌面应用，但还需处理 Node/Chromium 随包分发、Apple Silicon / Intel 架构、窗口及服务生命周期、自动更新和不同电脑的 CLI 路径。

- 内部测试并非必须先持有 Developer ID 才能开发运行；未签名、未公证的下载应用可能被 Gatekeeper 阻止，需要用户在系统设置中显式允许，企业管理策略也可能不允许。
- 为同事提供顺畅的正式下载使用体验，推荐 Developer ID 签名 + Apple 公证 + 附加公证票据；无需上架 Mac App Store。
- “做成一个执行文件”并不会自动绕过 Gatekeeper，原生可执行文件同样涉及签名与分发规则。当前 Node 源码启动包是不同交付方式，仍需用户安装可信运行环境。
- 此次未申请开发者账号、证书，也未签名或提交公证。

依据：[Apple：安全打开 Mac App](https://support.apple.com/en-gb/102445)、[Developer ID](https://developer.apple.com/developer-id/)、[公证文档](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution)。

## 共享模式补充

仅服务电脑本机管理员可保存设置和测试连接。成员最近任务按浏览器身份和当前共享文档过滤，不能查看或取消其他身份的任务。服务串行执行 AI，请求可排队，运行和等待共最多 8 个。排队可取消，重启时未完成任务标记中断，不会自动重跑；已保存候选可从“历史与候选”接回。

## 审阅与部分接受

候选的“审阅修改”同时显示基线和候选，支持同步缩放、平移和变化定位。勾选完整操作组后，“生成所选修改预览”将选中变化合并到最新图稿。非冲突人工修改保留；有冲突时显示涉及的操作组，取消勾选后重试。生成新候选后需再次预览才能应用。部分接受后的历史标记“部分已应用”，原始候选仍保留。

“清空会话”只清空当前模型上下文；“删除历史记录”删除服务器记录。命名方案仍受保留期限与容量限制，需要永久保留时下载 `.drawio`，也可导入文件库成为独立图稿。历史不保存 CLI 原始日志。备份数据目录时应包含 `ai-history.sqlite` 及运行中的 WAL/SHM，或停止服务后复制。
