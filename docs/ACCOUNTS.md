# 账号与本机用户管理 · v1.6.0

文件和分享授权绑定稳定的用户 ID。登录名唯一、不区分大小写，显示姓名可以重复；同一账号从不同浏览器登录，仍然使用同一份文件归属与分享权限。

## 普通用户

- 新用户在登录页选择“注册新账号”，填写登录名、显示姓名和密码。登录名为 3–40 位字母、数字、下划线、点或短横线；密码为 6–128 个字符，不限制字符组合，纯数字、纯字母或其他字符均可。不恢复旧版工作区访问码。
- 勾选“记住登录 30 天”会把随机登录凭证保存在当前站点的 localStorage，关闭浏览器后可继续使用；到期后用原账号密码登录即可，不会生成新用户。未勾选时使用 sessionStorage，服务器凭证有效期为一天；公共电脑使用后仍应明确退出登录。
- 更换浏览器、地址或清理站点数据后，使用原登录名和密码重新登录。仅填写相同显示姓名注册会创建另一个身份，不能认领原文件。
- 文件库顶部的“账号设置”支持修改密码。需要输入原密码；修改成功撤销其他旧登录、重置凭证和该用户的编辑锁，当前页面换发新凭证。
- “退出登录”使当前凭证失效，保留用户记录和全部数据；为避免遗留编辑权，同时释放该身份持有的编辑锁。
- 忘记登录名或密码时，联系本机管理员核实身份。管理员能查看登录名并签发一次性密码设置凭证。用户在登录页选择“忘记账号或密码”，输入凭证并自行设置密码。
- 一次性凭证有效期为 15 分钟，只能成功使用一次。过期、丢失或已经使用时由管理员重新签发；再次签发使旧凭证失效。不要将凭证发给其他人。

## 现有用户升级

升级保留已有身份 ID、有效浏览器凭证、文件、个人模板和分享授权。原浏览器首次打开会看到“为原身份设置账号”，选择未被占用的登录名并设置密码即可，服务器会将账号绑定到原 ID，而不是另建身份。补设完成后旧会话被撤销，当前浏览器取得新会话。

如果原浏览器数据已经丢失，不要用同名注册来尝试找回。管理员可在用户管理中找到原身份，为它设置登录名并发放密码设置凭证；核实身份后仍能恢复到原用户。没有完整身份或无法确认归属时，可先停用旧身份，再将图稿转移给确认的账号。旧显示姓名相同的用户不会自动合并。

迁移保留旧的凭证有效期，不复活已经过期的凭证。旧身份的创建时间按迁移时间补记，原来没有登录时间记录时显示“暂无登录记录”。

## 管理员入口与操作

默认在运行服务的电脑打开 `http://127.0.0.1:4317/admin/users`，或进入首页点击“用户管理”。如果服务启用了下文的原生 HTTPS，相应使用 `https://127.0.0.1:4317/admin/users`。管理员凭证仅提供给匹配本机地址的 loopback 请求；从局域网地址访问仍然是普通成员，姓名叫“管理员”也没有特权。

用户列表显示登录名、显示姓名、身份编号、状态、创建时间、最近登录、图稿数量（含回收站）、个人模板数量和未过期会话数量，支持搜索。会话数量不等于正在在线的人数。

| 操作 | 行为 |
| --- | --- |
| 创建用户 | 设置登录名与姓名，生成一次性凭证，由本人设置密码；不显示或代存明文密码 |
| 重置密码 | 先核实本人身份，立即撤销原密码、所有旧登录、旧重置凭证和编辑锁，生成新的一次性凭证 |
| 停用 | 立即拒绝该用户后续 API 访问，撤销会话和编辑锁；文件、个人模板与历史保留 |
| 启用 | 允许重新登录；旧会话不会恢复。如果此前尚未完成密码设置，重新签发设置凭证 |
| 转移图稿 | 原用户必须先停用；接收人必须启用且完成账号设置；转移全部图稿，包括回收站中的图稿 |
| 删除用户 | 必须先停用且名下没有图稿和个人模板；保留身份记录及原登录名占用，避免新用户冒用历史身份 |

转移图稿前，所有待转移图稿都不能有有效编辑锁；任一文件被编辑则整批失败。转移后文件所有者变为接收人，所有分享收回为私有，由接收人重新授权。原创建人文字、内容、内容版本、历史和回收站状态保持。列表“我拥有的”按当前归属筛选，“创建人”仍是历史创建记录。

个人模板不随图稿转移；有个人模板的原用户可以保持停用以保留数据，不能直接删除。需要保留其原有个人模板使用方式时，优先帮助本人恢复原账号。

账号管理操作记录在 `workspace.sqlite` 的 `account_audit` 中，不记录密码或一次性凭证。用户管理使用版本检查，旧列表上的冲突操作会被拒绝，刷新列表再操作。

服务器撤销权限即时生效。已经打开的页面会在会话检查时退回登录，正常网络下最长约 10 秒；期间后端已拒绝请求。已经下载、截图或缓存的数据不能远程收回。

## HTTPS 配置

程序支持工作台和画布同时启用 HTTPS。准备由访问设备信任的证书及私钥，然后运行：

```sh
node bin/zhitu.mjs --lan-host 192.168.1.10 --port 4317 --editor-port 4318 \
  --tls-cert /绝对路径/server-cert.pem --tls-key /绝对路径/server-key.pem
```

证书应包含实际访问的主机名或 IP，若需要本机管理入口也包含 `127.0.0.1`。工作台与画布使用同一组证书。私钥保存在工作区发布包之外并限制文件权限。两个参数必须同时提供；HTTPS 模式使用生产构建，不支持 `--dev`。

没有提供证书时保留 HTTP 兼容模式；这不等于已经加密，HTTP 下密码和会话可能被网络观察者获取。正式使用密码账号应部署可信 HTTPS。程序不会自动安装根证书、修改系统信任或擅自跳过访问者浏览器的证书检查。

切换 HTTP 到 HTTPS 会改变浏览器站点存储。请先在原地址补设固定账号，之后用账号密码登录 HTTPS 地址；若已经切换且没有补设，可由本机管理员为原身份签发设置凭证。图稿 ID、归属与数据库不随协议变化。

## 存储与保护

- `workspace_users`：稳定用户 ID、唯一登录名、显示姓名、密码哈希、状态及时间。
- `sessions`：随机会话 token 的 SHA-256 摘要与到期时间；不保存明文 token。
- `account_resets`：一次性随机凭证的 SHA-256 摘要及过期时间。
- 密码采用随机盐和 scrypt（N=32768、r=8、p=3、64 字节输出），不与旧版历史密码兼容或自动复用。
- 注册、登录、密码设置和修改入口按来源 IP 与路径限流，每分钟最多 10 次。
- 本机管理员保留管理所有文件的能力，普通账号不提供自提权入口。

备份时停止服务后复制完整数据目录，包含 `workspace.sqlite`、`templates.sqlite` 及存在的 WAL/SHM；或者使用 SQLite 的一致性备份方式。备份属于私有数据，不得装入分享安装包。
