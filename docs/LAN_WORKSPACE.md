# 局域网共享工作区 · v1.6.0

本版支持多人查看同一份图稿、单人持有编辑锁、自动保存和其他页面自动更新。每份图稿有独立地址，保存在运行服务的电脑上；不提供多人同时修改同一画布的实时合并。

## 启动与加入

本版最低要求 Node.js 22.22，推荐 24 LTS。共享存储使用 Node 内置 SQLite，版本下限与本轮实测环境保持一致。

在服务电脑安装依赖、完成构建后运行：

```sh
npm run build
node bin/zhitu.mjs --lan-host 192.168.1.10 --port 4317 --editor-port 4318
```

将 `192.168.1.10` 替换为服务电脑实际的局域网 IPv4 地址或内网主机名，不要填写 `0.0.0.0`。工作台和独立画布分别使用 4317、4318 两个端口，需允许局域网访问。建议为服务器固定地址。所有人打开同一个 `http://192.168.1.10:4317/`；其他电脑上的 `127.0.0.1` 指向其他电脑自身。

首次访问可注册固定账号，填写唯一登录名、显示姓名和密码；支持记住登录 30 天。换浏览器后用原账号密码登录，文件与分享权限不变。显示姓名可以重复，但相同姓名不能认领原身份。

已有浏览器会话在升级后显示补设账号页面，保留原身份 ID、文件、个人模板和分享。原浏览器数据丢失时，由本机管理员核实身份后帮助原用户设置账号和密码。密码找回、管理用户和 HTTPS 配置详见 [账号与用户管理](ACCOUNTS.md)。旧版历史密码不自动恢复，也不重新启用工作区访问码。

不传 `--lan-host` 时仍只监听本机，主页变为文件库，并以本机管理员身份打开。`/local` 保留原有临时画布和示例。局域网模式下，服务电脑打开 `http://127.0.0.1:4317/` 自动进入本机管理员界面；通过局域网地址访问则作为普通成员加入。管理员身份只向本机请求提供，旧远程管理员会话转为成员。现有浏览器草稿不会自动上传：可先在临时画布恢复，再点击“保存到文件库”。

可用 `--data-dir /绝对路径/团队图稿` 指定持久化目录；默认是服务电脑上的 `~/.ai-zhitu`。服务需保持运行。局域网 HTTP 适用于可信内网，传输未加密；可通过证书参数启用原生 HTTPS，配置见账号指南；不提供公网托管或租户隔离。

## 管理员如何确认

在运行服务的电脑上打开 `http://127.0.0.1:4317/`（自定义端口时对应替换），顶部会显示“本机管理员 · 管理员”，并出现“用户管理”。管理员能管理全部文件、修改 AI 配置，并从“用户管理”创建、停用、重置、转移图稿和删除用户。这个权限由本机访问入口决定，不通过用户名授予；在服务电脑上使用局域网地址，也仍按普通成员进入。其他电脑上的 `127.0.0.1` 指向其自身，不能作为远程管理员入口。

## 新建与自动保存

1. 点击“新建图稿”，选择空白或模板。初始内容只保留在当前标签页，尚未创建服务器文件；不修改直接返回不会在文件库留下空稿。缩放、选中图形和拖动画布不算修改。在未修改的空白稿中选择模板，也只作为初始内容。
2. 首次修改图形、文字、样式或图稿名称后，约 2 秒自动创建私有文件，直接出现在“全部文件”；文字编辑结束后再保存。首次写入时短暂暂停编辑，保存成功后进入独立文档地址并继续编辑。点击“← 文件库”会提交尚未保存的修改再返回。
3. 想保留未经修改的空白或模板，可主动点击“保存到文件库”。从文件库导入 `.drawio` / XML 是明确保存操作，会直接创建私有文件。
4. 不再区分“我的草稿”和正式文件，也不需要再次发布。已有服务器草稿自动合并到“全部文件”，原 ID、内容、名称、创建人、版本与回收站状态保留，仍然私有；浏览器本地恢复草稿不自动上传。
5. 保存与分享相互独立：保存不开放访问。创建者通过分享窗口授权指定成员或所有成员后，对方才可访问。
6. 已有文件打开时默认只读，点击“获取编辑权”后修改；每份文档只有一个标签页持有编辑权，不同图稿可分别编辑。后续修改约每 2 秒自动保存。
7. 首次保存失败时保留当前内容并提供重试。若服务器已写入但响应丢失，重试仍返回同一文件，不重复创建；待确认内容保存在当前标签页中，刷新后可以继续重试。不要清理站点存储或关闭尚未完成保存的标签页。

## 分享范围与收回

点击文件库的分享图标或编辑页的“分享链接”，选择范围后点击“保存分享权限”：

| 范围 | 谁可以访问 |
| --- | --- |
| 仅自己 | 创建者与本机管理员；其他人拿到链接也不能访问 |
| 指定成员 | 创建者、选中的账号与本机管理员 |
| 所有成员 | 当前及以后加入此工作区的成员 |

- 打开分享窗口或复制链接不会自动授权。选择尚未保存时，复制按钮暂时禁用，避免发送未生效的链接。权限保存后再点“复制链接”；自动复制失败时可以选中链接手动复制。
- 指定成员必须先在该工作区注册账号或完成管理员提供的账号设置。成员列表显示姓名、登录名和身份编号；请核对对方的登录名或文件库中的“我的身份”编号，避免选错同名成员。换浏览器、换站点地址或清理站点数据后，用原账号密码登录即可恢复同一身份与权限。显示姓名不证明真实身份。
- 已授权成员可查看、导出并申请单人编辑锁，但不能修改分享权限；只有创建者或本机管理员可以调整范围。转发链接不会给未授权者增加权限。
- 改回“仅自己”或取消某位成员后，服务器立即拒绝其后续读取、历史和保存请求，并清除该成员的编辑锁。已打开的在线页面约 2 秒内移除画布，文件库会在轮询后移除文件；重新获授权后刷新可恢复访问。
- 收回权限无法删除对方此前已下载、截图或保存在浏览器中的副本；未同步编辑在收回后不能继续写入服务器。
- 分享权限有独立版本号，不增加图稿内容版本，也不会使创建者的自动保存发生内容版本冲突。多窗口同时改权限时，后提交的旧版本请求会被拒绝，请重新打开分享窗口。

升级到 v1.4 时，旧版本没有完整的主动分享记录，所有旧文件会默认收回为仅创建者与本机管理员可见。文件内容、创建人、版本、文件库状态和链接保留，不删除文件。需要协作的文件请重新设置分享范围。此迁移只执行一次，后续启动保留设置好的权限。

服务器文件跨服务重启保留，浏览器恢复草稿依赖当前浏览器站点数据。更换浏览器或清理站点数据后使用原账号密码重新登录即可访问原服务器文件；尚未修改的新图稿没有上传到服务器。

## 文件库管理与编辑

- 文件库包含“全部文件”和“回收站”，支持搜索、“我拥有的”筛选与当前文件数量显示。
- 列表分别显示“创建人”和“最后保存人 / 时间”。创建人持久记录，不随后续编辑者变化。
- 点击图稿名称打开文件；需要改名时，获取编辑权后修改编辑页顶部的图稿名称。操作列仅显示分享和垃圾桶图标，所有已保存文件均可设置分享权限。创建者或管理员点击垃圾桶，确认后移入回收站。有人正在编辑时垃圾桶禁用，后端也拒绝操作；请先结束编辑或等待异常断线租约到期。
- 勾选文件后可批量移入回收站，每次最多 100 份。服务器在同一个事务中检查全部文件的权限、版本和编辑锁；任一文件不满足条件则整批失败，不会只处理一部分。发生版本冲突后重新确认列表再选择。
- 回收站中可以恢复文件。恢复后回到“全部文件”，保留原分享范围，没有永久删除或自动清理入口。
- 编辑内容或顶部名称后约每 2 秒自动保存，也可点击“保存到服务器”。共享文件保存后，其他只读页面约 2 秒内加载新内容。
- “结束编辑”先保存后释放锁。正常关闭页面尝试立即释放；断网或崩溃后，最后一次续约 30 秒后可接管。
- “保存副本”和“保存到文件”下载或写入访问者自己的磁盘，不替代服务器保存，也不清除未同步状态。局域网 HTTP 不支持直接写文件时退回下载，PNG、SVG、PDF 导出仍可使用。

## 断线、冲突与恢复

- 心跳失败或编辑锁到期后，页面暂停编辑并保留当前内容，不自动用远端版本覆盖未同步修改。浏览器恢复草稿仍是辅助恢复手段。
- 恢复联网后，可以重新获取编辑权。如果服务器版本没有变化，可继续保存当前修改；如果别人已保存新版，系统拒绝覆盖。
- 冲突时先点“保存副本”下载未同步图稿，再点“加载最新版本”。放弃未同步修改前有确认。需要合并时，可将备份导入为另一份图稿，手动整理。
- 刷新正常已保存的文档会重新打开同一地址；刷新前仍有未同步修改时，应先下载副本或使用恢复草稿。
- 每次内容或名称变化的保存会生成服务器版本，保留每份文档最近 50 版。无变化的重复保存不增加版本。恢复历史版本需要编辑权，并产生新的版本；恢复前会先保存当前未保存内容。
- 创建者或管理员可在文件库移入回收站，也可在编辑页保存当前内容后移入回收站。恢复保留文件内容和分享权限，没有永久删除入口。

## AI 使用

服务器管理员在设置中配置并登录服务器上的 Codex/Qoder CLI。团队成员使用这台服务器的 AI 客户端和额度，而不是自己电脑上的 CLI。

- 只有管理员可修改客户端路径、检测或测试连接。
- 每个账号只能查看、接回和取消自己发起的 AI 任务；共享文档内的最近任务按文档过滤。
- 修改共享图稿前需要编辑权，候选应用同样受画布只读限制。AI 结果不会绕过服务器版本检查。
- AI 请求按进入顺序执行，同一服务最多一个正在执行，运行和等待总计最多 8 个任务。取消排队任务不会调用模型。
- 结束编辑不自动取消已提交的 AI 请求；候选仍属于提交者。重新应用需再次获得编辑权，并核对候选基线。
- AI 任务与队列是内存状态，服务重启后清空。需要保留的候选请下载，或应用并保存到共享文档。

## 数据位置与备份

| 数据 | 位置 |
| --- | --- |
| 已保存文件、创建人、分享范围与成员授权、服务器版本、回收站、浏览器身份会话、编辑租约 | 数据目录的 `workspace.sqlite` |
| SQLite 正在运行的事务日志 | 同目录 `workspace.sqlite-wal` / `workspace.sqlite-shm` |
| AI 客户端配置 | 同目录 `clients.json` |
| 恢复草稿、本地版本和最近颜色 | 各访问者的浏览器存储 |
| AI 任务和导出任务 | 服务内存与临时文件 |

最简单的完整备份方式：正常停止服务，复制整个数据目录，再启动服务。恢复时停止服务，将备份目录作为 `--data-dir` 启动。不要在服务运行时只复制 SQLite 主文件，可能漏掉 WAL 中已提交的内容。备份包含浏览器身份和访问凭据，应按团队数据管理。

新建文件默认私有；文件列表、直接地址、历史版本、编辑与 AI 文档请求均在服务器校验访问权限。列表管理和删除/恢复仅限当前所有者或管理员；团队分组、文件夹、按查看/编辑角色进一步分权和实时合并不属于本版能力。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 同事打不开页面 | 检查地址是否为服务器内网 IP，确认端口、防火墙和服务状态 |
| 文件库能打开但画布加载失败 | 检查第二个画布端口是否允许访问；分享同一个配置的主机名 |
| 无法获取编辑权 | 查看谁在编辑，请对方结束编辑；异常断线后等待租约到期 |
| 已保存内容没更新 | 检查网络状态、当前页面是否保留了未同步修改；必要时先下载再加载最新版本 |
| 改端口或换浏览器后草稿不见 | 浏览器恢复草稿依赖站点数据；已保存的服务器文件仍保留，可用原账号密码重新登录，或由本机管理员帮助恢复 |
| 有链接却无法打开 | 请创建者确认分享范围及你的身份编号；同名新账号不会继承授权，换浏览器请登录原账号 |
| 升级后同事的文件不见了 | v1.4 默认收回旧分享，请创建者重新授权；本机管理员可查看原文件 |
| AI 排队 | 等待先前任务结束，或取消自己的排队任务 |
| 重启后编辑锁短暂存在 | 租约在数据库中保存，最后一次续约后 30 秒自然失效 |

实现和测试入口见 [技术设计](design/TECHNICAL_DESIGN.md) 与 [v1.4 分享权限验证报告](testing/V1_4_SHARING_REPORT.md)。
