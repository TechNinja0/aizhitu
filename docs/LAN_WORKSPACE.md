# 局域网共享工作区 · v1.6.0

本版支持分享读写权限和多人协同。自己的文件默认编辑，别人分享的文件默认查看；获准编辑的成员点击右上方“编辑”进入编辑态，再次点击保存并退回查看。无需申请独占编辑权。协同按对象属性合并，编辑时约每秒同步，空闲时降低检查频率；每份图稿有独立地址，保存在运行服务的电脑上。

## 启动与加入

本版最低要求 Node.js 22.22，推荐 24 LTS。共享存储使用 Node 内置 SQLite，版本下限与本轮实测环境保持一致。

在服务电脑安装依赖、完成构建后运行：

```sh
npm run build
node bin/zhitu.mjs --lan-host 192.168.1.10 --port 4317 --editor-port 4318
```

将 `192.168.1.10` 替换为服务电脑实际的局域网 IPv4 地址或内网主机名，不要填写 `0.0.0.0`。工作台和独立画布分别使用 4317、4318 两个端口，需允许局域网访问。建议为服务器固定地址。所有人打开同一个 `http://192.168.1.10:4317/`；其他电脑上的 `127.0.0.1` 指向其他电脑自身。

首次访问可注册固定账号，填写唯一登录名、显示姓名和密码；支持记住登录 30 天。换浏览器后用原账号密码登录，文件与分享权限不变。显示姓名可以重复，但相同姓名不能认领原身份。

已有浏览器会话在升级后显示补设账号页面，保留原身份 ID、文件、个人模板和分享。原浏览器数据丢失时，由本机管理员核实身份后帮助原用户设置账号和密码。密码找回、管理用户和 HTTPS 配置详见 [账号与用户管理](ACCOUNTS.md)。旧版历史密码不自动恢复，也不重新启用工作区访问码。

不传 `--lan-host` 时仍只监听本机，主页变为文件库，并以本机管理员身份打开。`/local` 保留原有临时画布和示例。局域网模式下，服务电脑打开 `http://127.0.0.1:4317/` 自动进入本机管理员界面；通过局域网地址访问则作为普通成员加入。管理员身份只向本机请求提供，旧远程管理员会话转为成员。现有浏览器草稿不会自动上传：可先在临时画布恢复，再点击“保存到文件库”。

可用 `--data-dir /绝对路径/团队图稿` 指定持久化目录；默认是服务电脑上的 `~/.ai-zhitu`。服务需保持运行。局域网 HTTP 适用于可信内网，传输未加密；可通过证书参数启用原生 HTTPS，配置见账号指南；不提供公网托管或租户隔离。

## 管理员如何确认

在运行服务的电脑上打开 `http://127.0.0.1:4317/`（自定义端口时对应替换），顶部会显示“本机管理员 · 管理员”，并出现“用户管理”。管理员能管理全部文件、修改 AI 配置，并从“用户管理”创建、停用、重置、转移图稿和删除用户。这个权限由本机访问入口决定，不通过用户名授予；在服务电脑上使用局域网地址，也仍按普通成员进入。其他电脑上的 `127.0.0.1` 指向其自身，不能作为远程管理员入口。

## 新建与自动保存

1. 点击“新建图稿”，选择空白或模板。初始内容只保留在当前标签页，尚未创建服务器文件；不修改直接返回不会在文件库留下空稿。缩放、选中图形和拖动画布不算修改。在未修改的空白稿中选择模板，也只作为初始内容。
2. 首次修改图形、文字、样式或图稿名称后，约 2 秒自动创建私有文件，直接出现在“全部文件”；文字编辑结束后再保存。首次写入时短暂暂停编辑，保存成功后进入独立文档地址并继续编辑。点击“← 文件库”会提交尚未保存的修改再返回。
3. 想保留未经修改的空白或模板，可主动点击“保存到文件库”。从文件库导入 `.drawio` / XML 是明确保存操作，会直接创建私有文件。
4. 不再区分“我的草稿”和正式文件，也不需要再次发布。已有服务器草稿自动合并到“全部文件”，原 ID、内容、名称、创建人、版本与回收站状态保留，仍然私有；浏览器本地恢复草稿不自动上传。
5. 保存与分享相互独立：保存不开放访问。创建者通过分享窗口授权指定成员或所有成员后，对方才可访问。
6. 自己的已有文件、导入后的文件和新图稿首次保存后的页面，自动连接后可编辑；别人分享的文件默认只读，拥有可编辑授权的成员可主动切换编辑。正常网络下有修改时约每秒自动同步，状态栏根据私有/分享范围、单人/多页情况显示保存结果，不提供“保存到服务器”按钮。连接过程中保持只读，暂时失败自动重试。
7. 首次保存失败时保留当前内容并提供重试。若服务器已写入但响应丢失，重试仍返回同一文件，不重复创建；待确认内容保存在当前标签页中，刷新后可以继续重试。不要清理站点存储或关闭尚未完成保存的标签页。

## 分享范围与收回

点击文件库的分享图标或编辑页的“分享链接”，选择范围后点击“保存分享权限”：

| 范围 | 谁可以访问 |
| --- | --- |
| 仅自己 | 创建者与本机管理员；其他人拿到链接也不能访问 |
| 指定成员 | 创建者、选中的账号与本机管理员 |
| 所有成员 | 当前及以后加入此工作区的成员 |

- 打开分享窗口或复制链接不会自动授权。选择尚未保存时，复制按钮暂时禁用，避免发送未生效的链接。权限保存后再点“复制链接”；自动复制失败时可以选中链接手动复制。
- 指定成员必须先在该工作区注册账号或完成管理员提供的账号设置。成员列表显示姓名、登录名和身份编号；请核对对方的登录名或文件库中的“我的身份”编号，避免选错同名成员。换浏览器、换站点地址或清理站点数据后，用原账号密码登录即可恢复同一身份与权限。显示姓名不证明真实身份。
- 分享同时设置“仅查看 / 可编辑”，新分享默认仅查看；指定成员可逐人选择，所有成员使用统一权限。可查看者能读取、导出和接收更新，不能修改原文件；可编辑者可以主动切换编辑，但不能转授权。只有所有者或本机管理员可以调整分享。转发链接不会增加权限。
- 接收者每次重新打开或刷新链接都默认查看，点击“编辑”后按钮显示选中状态；再次点击先保存，成功才退回查看，失败保留编辑态与内容。仅查看角色没有这个按钮。查看页不创建编辑会话，不阻止作者恢复历史或删除。
- 从可编辑降为仅查看时，服务器立即撤销写权限与会话。无未保存修改的编辑页自动回到查看；有未同步内容时暂停并保留内容供下载，不能再写入原文件。
- 本次升级将已有分享保留为可编辑；新文件首次分享默认仅查看。迁移只执行一次，不重置已设置的角色。
- 改回“仅自己”或取消某位成员后，服务器立即拒绝其后续读取、历史和保存请求，并清除该成员的编辑锁和协同会话。已打开的协同页面在后续请求发现撤权时暂停并只读，以便下载本地副本；未授权用户首次打开则不显示画布，文件库会在轮询后移除文件；重新获授权后刷新可恢复访问。
- 收回权限无法删除对方此前已下载、截图或保存在浏览器中的副本；未同步编辑在收回后不能继续写入服务器。
- 分享权限有独立版本号，不增加图稿内容版本，也不会使创建者的自动保存发生内容版本冲突。多窗口同时改权限时，后提交的旧版本请求会被拒绝，请重新打开分享窗口。

升级到 v1.4 时，旧版本没有完整的主动分享记录，所有旧文件会默认收回为仅创建者与本机管理员可见。文件内容、创建人、版本、文件库状态和链接保留，不删除文件。需要协作的文件请重新设置分享范围。此迁移只执行一次，后续启动保留设置好的权限。

服务器文件跨服务重启保留，浏览器恢复草稿依赖当前浏览器站点数据。更换浏览器或清理站点数据后使用原账号密码重新登录即可访问原服务器文件；尚未修改的新图稿没有上传到服务器。

## 文件库管理与自动协同

- 文件库包含“全部文件”和“回收站”，支持搜索、“我拥有的”筛选与当前文件数量显示。
- 顶部账号区、工具栏与表头固定，只有文件列表滚动，底部分页始终可见。默认每页 10 条，可选 20／50／100 条并由当前浏览器记住；翻页、筛选或调整每页数量时清空勾选，删除最后一页的全部文件后自动返回有效页。
- 文件库使用服务器分页，每 3 秒只刷新当前页摘要与符合权限、搜索条件的总数，不读取图稿正文。搜索覆盖所有有权访问的文件。旧调用不带分页参数时仍返回数组，新接口 `GET /api/documents?page=1&pageSize=10&q=关键词` 返回 `{ items, total, page, pageSize }`；先按权限过滤再计数、分页，每页最多 100 条。
- 列表分别显示“创建人”和“最后保存人 / 时间”。创建人持久记录，不随后续编辑者变化。
- 点击图稿名称打开文件；需要改名时，连接就绪后修改编辑页顶部的图稿名称。操作列仅显示分享和垃圾桶图标，所有已保存文件均可设置分享权限。创建者或管理员点击垃圾桶，确认后移入回收站。有人正在编辑时垃圾桶禁用，后端也拒绝操作；请让相关编辑页面切换为仅查看或返回文件库，或等待异常断线会话到期。
- 勾选本页文件后可批量移入回收站，每次最多 100 份，“全选”只选中本页可管理文件。服务器在同一个事务中检查全部文件的权限、版本和在线协同状态（同时兼容旧编辑锁）；任一文件不满足条件则整批失败，不会只处理一部分。发生版本冲突后重新确认列表再选择。
- 回收站中可以恢复文件。恢复后回到“全部文件”，保留原分享范围，没有永久删除或自动清理入口。
- 编辑内容或顶部名称后约每秒同步，状态栏显示结果，其他协同页面自动合并变化。仅打开、选中和缩放不会生成新版本。
- “← 文件库”、通过“新建 / 打开”切换文件或退出编辑，都会先冻结编辑、提交正在输入的文字并等待最后一次同步成功，再切换；失败保留页面与内容。正常关闭页面尽力释放会话；断网或崩溃后，会话在最后一次续约 30 秒后失效。直接关闭无法保证保存最后的修改。
- “下载副本”和“保存到文件”下载或写入访问者自己的磁盘，不替代服务器保存，也不清除未同步状态。局域网 HTTP 不支持直接写文件时退回下载，PNG、SVG、PDF 导出仍可使用。

## 断线、冲突与历史恢复

- 已进入协同后断网，可继续在当前页编辑；恢复网络后自动重试并合并变化，不重置本地基线。首次连接尚未成功时保持只读。
- 基线超出最近 50 版、文档校验失败或权限失效时暂停同步。先“下载副本”保留内容，处理原因后点击“重新连接”加载服务器最新内容；存在未同步修改时会要求确认。重新连接会放弃当前未同步修改，必要时把副本导入另一份图稿整理。
- 刷新会重新打开同一地址：自己的文件默认编辑，别人的文件默认查看，但不会自动续传刷新前的内存队列。浏览器“恢复草稿”是辅助找回副本的入口，不能代替服务器确认。
- 内容或名称变化才生成服务器版本，每份文档最多保留最近 50 版，总 XML 容量预算 64 MiB；大图超额时逐步淘汰最旧版本，但至少保留最近两版。编辑页“服务器版本”中恢复会先保存当前修改，再生成新版本并继续协同，同时清空当前页旧撤销记录；其他编辑页面仍在线时，服务器拒绝恢复；查看页不占用编辑会话。
- 创建者或管理员可在编辑页移入回收站，但须先让其他编辑页面切换为仅查看或返回文件库。文件库单个或批量回收则要求没有任何在线编辑页面；服务器事务再次检查，不会仅依赖按钮状态。回收站恢复保留内容和分享权限，没有永久删除入口。

## AI 使用

服务器管理员在设置中配置并登录服务器上的 Codex/Qoder CLI。团队成员使用这台服务器的 AI 客户端和额度，而不是自己电脑上的 CLI。

- 只有管理员可修改客户端路径、检测或测试连接。
- 每个账号只能查看、接回和取消自己发起的 AI 任务；共享文档内的最近任务按文档过滤。
- 协同连接就绪后可修改共享图稿；AI 请求携带当前协同会话，候选应用同样受连接状态和画布只读限制，不能绕过服务器权限与内容检查。
- AI 请求按进入顺序执行，同一服务最多一个正在执行，运行和等待总计最多 8 个任务。取消排队任务不会调用模型。
- 返回文件库不会自动取消已提交的 AI 请求；候选仍属于提交者。重新打开图稿后，等待协同连接就绪，再核对候选基线并应用。
- AI 任务与队列是内存状态，服务重启后清空。需要保留的候选请下载，或应用并保存到共享文档。

## 数据位置与备份

| 数据 | 位置 |
| --- | --- |
| 已保存文件、创建人、分享范围与成员授权、服务器版本、回收站、账号会话、成员读写角色、在线协同会话、幂等回执及兼容旧版的编辑租约 | 数据目录的 `workspace.sqlite` |
| SQLite 正在运行的事务日志 | 同目录 `workspace.sqlite-wal` / `workspace.sqlite-shm` |
| AI 客户端配置 | 同目录 `clients.json` |
| 恢复草稿、本地版本和最近颜色 | 各访问者的浏览器存储 |
| AI 任务和导出任务 | 服务内存与临时文件 |

最简单的完整备份方式：正常停止服务，复制整个数据目录，再启动服务。恢复时停止服务，将备份目录作为 `--data-dir` 启动。不要在服务运行时只复制 SQLite 主文件，可能漏掉 WAL 中已提交的内容。备份包含浏览器身份和访问凭据，应按团队数据管理。

新建文件默认私有；文件列表、直接地址、历史版本、编辑与 AI 文档请求均在服务器校验访问权限。列表管理和删除/恢复仅限当前所有者或管理员；团队分组、文件夹、按查看/编辑角色进一步分权及逐字符合并不属于本版能力。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 同事打不开页面 | 检查地址是否为服务器内网 IP，确认端口、防火墙和服务状态 |
| 文件库能打开但画布加载失败 | 检查第二个画布端口是否允许访问；分享同一个配置的主机名 |
| 一直显示正在连接协同 | 检查网络与权限；最多允许 32 个同时在线编辑页面。旧版页面仍持锁时，请其保存并关闭，或等待旧租约到期 |
| 已保存内容没更新 | 检查网络状态、当前页面是否保留了未同步修改；暂停时先下载副本再重新连接 |
| 改端口或换浏览器后草稿不见 | 浏览器恢复草稿依赖站点数据；已保存的服务器文件仍保留，可用原账号密码重新登录，或由本机管理员帮助恢复 |
| 有链接却无法打开 | 请创建者确认分享范围及你的身份编号；同名新账号不会继承授权，换浏览器请登录原账号 |
| 升级后同事的文件不见了 | v1.4 默认收回旧分享，请创建者重新授权；本机管理员可查看原文件 |
| AI 排队 | 等待先前任务结束，或取消自己的排队任务 |
| 已关页面仍显示在线，无法恢复或删除 | 异常断线会话在最后一次续约后 30 秒自然失效 |

实现和测试入口见 [技术设计](design/TECHNICAL_DESIGN.md) 与 [v1.4 分享权限验证报告](testing/V1_4_SHARING_REPORT.md)。


## 多人同时编辑

保存分享权限后，拥有编辑授权的成员打开链接先查看，主动点击“编辑”才加入协同；自己的文件默认编辑。同一个人的多个编辑标签页也分别接入。查看页自动获取最新版本，但不占编辑会话。状态栏直接列出正在编辑者的姓名，当前账号标注“你”；仅查看时也能看到编辑者。单人编辑只显示“编辑中”，多人不重复显示人数。同账号多页合并姓名，页面数、完整名单可悬停查看。正常状态简写为“已保存 / 已更新”，服务器版本号在状态悬停说明和“服务器版本”窗口查看。

状态栏私有时显示“仅自己可见”，分享后简写为“已分享”，具体范围可悬停查看。单人显示“编辑中”，多人直接列出编辑者姓名并标注“你”；查看态明确显示“仅查看”，同时展示实际编辑者。同账号多页合并姓名，完整名单与页面数可悬停查看；同名的不同账号按账号 ID 区分。不同对象、不同属性的修改保留；同一属性以后提交到服务器为准，文字标签按完整值合并，不按字符合并。撤销和重做只作用于本页操作，远端同步保留选区和缩放，不打断正在输入的文字。

同步检查策略：

| 情况 | 检查间隔 |
| --- | --- |
| 有未保存修改、在途提交或待应用响应 | 约 1 秒，后台也优先保存 |
| 前台多个页面同时打开 | 约 1 秒 |
| 前台单页且没有修改 | 约 5 秒 |
| 后台且没有修改 | 约 10 秒 |
| 回到前台或恢复网络 | 立即检查 |

空闲只检查服务器状态，不重复序列化本地画布或创建版本。单页发现其他页面加入最多约 5 秒；后台页面可能约 10 秒后更新。每次服务端检查仍验证权限；只有编辑页续约 30 秒会话，查看页只读取状态；浏览器休眠或节流可能延迟定时器，恢复后沿用原基线与请求 ID 重连，不自动覆盖本地修改。

每份图稿最多允许 32 个同时在线编辑页面，这是保护性上限，并非已验证的 32 人负载承诺。暂不提供远端光标、逐字符文本协同或跨服务器同步。部署更新需重新构建前端并重启服务；升级前让成员通过“← 文件库”完成保存，新版页面刷新后按文件归属进入编辑或查看态。
