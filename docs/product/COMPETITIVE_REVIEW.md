# 竞品对照与本轮产品优化

日期：2026-09-18。范围：本地网页、可分享启动包、现有单画布流程图/架构图。不封装 App，不引入服务器和团队账号。

## 结论

本产品目前的优势是复用本机 Codex/Qoder、保持可编辑原生文件、在本地校验和导出。现阶段主要差距不是再增加一种图稿名称，而是长时间编辑时找得快、改得稳、失败能继续、结果能找回。因此本轮优先补可靠性和编辑效率，而不照搬大型在线工具的全部菜单。

本次证据分为两类：竞品功能来自官方资料；本产品问题来自当前代码和浏览器测试。未对竞品付费账户进行逐项体验，不推断当前套餐权益和性能排名。

| 产品 | 官方资料中的能力 | 对本产品的启发 |

## 已有能力，不应误判为缺失

- 图形编辑、文字、端点绑定、分组/解组、缩放、对齐分布、基础样式与撤销重做由 draw.io 内核提供；不另写第二个编辑器。
- 原生文件、PNG/SVG/PDF、本地草稿、核对与原图对照已存在。
- CLI 设置、文字/截图生成、选区改稿、候选校验、预览与原子应用已经打通。
- 配置检测与 AI 实际响应的状态已区分，不能因为 CLI 存在就称为 AI 在线。
- 原有内容哈希已经包含核对元数据与几何数据。本轮任务恢复直接复用该哈希，不另造一套不同的内容身份定义。

## 发现的问题与本轮处理

| 问题 | 影响 | 本轮处理 |
| --- | --- | --- |
| 只有滚动恢复草稿和内存撤销，没有可命名的里程碑版本 | 难以回到评审前状态；刷新后撤销栈不在 | 加入手动版本、版本下载/恢复；恢复前备份、恢复可撤销；AI 应用前自动备份 |
| 刷新网页后任务还在服务端运行，页面却没有接回入口 | 用户找不到结果，也无法方便取消 | 新增最近任务列表，可接回运行任务或完成候选、取回失败要求、取消任务 |
| 刷新使编辑器修订号重新开始 | 即使图稿相同，旧任务也无法直接用旧修订号应用 | 用户接回时先比对完整图稿哈希与 documentId，一致才绑定当前修订号；内容不一致拒绝恢复候选 |
| 取消/失败后清空输入和截图 | 重试要重新输入和选图 | 取消/失败恢复本轮原要求与附件；已取消记录进入会话 |
| “检测”隐式保存整个设置表单，“测试”也顺带保存 | 用户未点保存却改变客户端配置 | 检测只读取当前路径；设置显式保存；关闭后丢弃未保存字段，连接测试要求先保存 |
| 异步重新读取设置可能覆盖刚输入的字段 | 用户输入被迟到的响应覆盖 | 打开设置使用已保存快照，不用异步回填覆盖编辑中的表单 |
| 会话候选要求预览，外部文件候选却可以跳过 | 两条修改入口行为不一致 | 均需先预览，均在应用前保存版本，并复用相同哈希/修订检查 |
| 批量应用候选时内核自动把部分边移入共同父容器 | 恢复版本或局部改稿意外改变无关连线父级 | 应用事务内临时关闭自动边归属调整，保留候选原有父级和相对几何；事务后恢复正常编辑规则 |
| 文件选择或写入期间切换图稿 | 可能把新图写入旧目标，或把新图误标已保存 | 按打开代次检查；提交前取消并 abort 写入；完成后只更新原图的保存状态 |
| 在复杂图里查对象需要依赖内核菜单或手工浏览 | 缺少明确入口，定位慢 | 增加按文字/ID 查找节点与连线的入口和结果定位 |
| AI 与核对/指南侧栏可同时打开挤占画布 | 画布空间不足 | 侧栏切换互斥；模型列表、任务和附件入口保持局部收纳 |
| 截图只支持文件选择 | 截图到会话要额外保存文件 | 会话支持粘贴、拖入 PNG/JPEG，保持原大小校验 |

## 本轮仍保留的边界

- 本地版本保存在当前浏览器、当前地址的 IndexedDB；每图最多 20 版、全局最多 40 MiB，超限清理最旧记录。换浏览器/端口或清理站点数据不会自动迁移。要长期保留或分享，用 `.drawio` 下载。
- 服务内任务最多保留一小时/30 个，列表展示最近 12 个。服务停止或重启会清空；不是持久任务数据库。刷新能接回原任务，不代表恢复完整历史聊天。失败任务可取回文字；已结束任务的截图临时文件仍按原策略清理。
- 自动版本保存失败时不会继续覆盖正式画布，而是提示存储问题。原稿仍可通过已有保存功能下载。
- 一键美化当前是可安全拉直的连线整理，不是自动重排整图、改主题或保证所有线不交叉。主按钮提示明确说明边界，后续整体布局需独立验收。
- 仅选区模式继续限制修改既有选区对象；向选区外新增模块/连线请用“修改当前图”。不借改名功能宣称已完成复杂图语义编辑。

## 后续缺口与优先级

| 优先级 | 功能 | 实施前应明确什么 |
| --- | --- | --- |
| 下一批 | 个人组件/模板库 | 选区存组件、独立 ID 重映射、连接边界、导入导出；不只是保存整张图 |
| 下一批 | 整图布局与布局质量检查 | 分组、锁定节点、人工折点、交叉/遮挡规则；保留当前确定性连线整理 |
| 下一批 | 本地项目/最近文件与会话持久化 | 浏览器存储和磁盘目录的职责、迁移与清理；不能把草稿称为正式文件管理 |
| 按需 | 思维导图/组织图模板、时序图 | 前两者先模板和布局；时序图要验证生命线、消息顺序与编辑语义 |
| 按需 | 多页、Mermaid 可编辑导入 | 页级身份、撤销、导出；Mermaid 语法子集和失败诊断 |
| 暂缓 | 图层高级管理/复杂图形库 | 开放内核菜单前保证 profile、AI 与导出的兼容性，不盲目开启所有库 |
| 暂缓 | MCP、仓库分析入口 | 前者用于外部 AI 控制当前画布；后者需明确授权仓库和上下文范围 |
| 不在当前范围 | 云同步、多人实时协作、账号权限、App 封装 | 与本轮本地分享目标不一致，不引入服务器成本和账号体系 |

## 验收重点

优先证明实际行为：检测不写设置；切图不误写文件；版本能跨刷新找回并可撤销恢复；运行任务跨刷新接回后仍核对基线；AI 失败/取消可重试；两条候选路径都不跳过预览。此轮不修改 Provider 的提示词、模型参数或截图识别算法，不用重复大批真实模型测试代替上述确定性回归。

## v1.1 主题与编辑效率补充

核实 [draw.io 样式](https://www.drawio.com/docs/manual/styles/)及[编辑器配色配置](https://www.drawio.com/docs/reference/configure-diagram-editor/)，并参考 [ProcessOn 色板与格式刷](https://www.processon.com/knowledge/xinshourumen)，本版采用主题卡片、自定义/最近颜色、外观复制与对齐分布。配色与界面由本项目实现，不复用竞品素材。优先保证候选能看清、能保留、能安全应用，暂不扩展云协作或复杂新图稿类型。
