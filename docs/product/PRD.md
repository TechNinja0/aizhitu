# AI智图 · 产品需求文档

版本：1.2.1 · 更新：2026-09-20。本文描述当前交付范围，替代早期文件交换版的产品基线。历史讨论见 [功能重整](ROADMAP_REVIEW.md)。

## 产品定位

面向开发者、技术写作者和小团队的本地结构化绘图工具。用户可以手工绘图，或通过已有 Codex/Qoder CLI 将文字与截图转成可编辑图稿，再核对、修改、保存和导出。文字、节点、容器和连线都是独立对象；整张截图作为背景不等于完成重建。

核心编辑、校验、保存、渲染在本机完成。AI 使用用户的客户端账号和额度，工作台不提供账号、模型 API 或免费额度。分发方式为本地启动包，支持本机与局域网服务部署，暂不提供桌面 App 或公网托管。

## 当前能力与交互要求

| 能力 | 当前产品要求 |
| --- | --- |
| 团队文件库 | 稳定文档 ID 与独立 URL；SQLite 持久化；文件列表、搜索、导入、重命名、回收站 |
| 多人访问 | 首次填写用户名、同一浏览器记住身份，单文档单标签页编辑租约；2 秒自动保存和只读同步；30 秒租约过期；版本冲突拒绝覆盖 |
| 服务器版本 | 每图最近 50 版；恢复产生新版本；创建者或管理员删除和恢复文件 |
| 文件与图稿 | 新建、打开、保存原生单页 `.drawio`；压缩/未压缩 XML 导入并校验；普通截图须通过 AI 重建 |
| 基础编辑 | 矩形、圆角矩形、椭圆、菱形、圆柱、文本、容器、嵌入 PNG/JPEG；编辑文字、移动缩放、复制粘贴、组合/解组、层级及锁定 |
| 连线 | 绑定端点、箭头、标签、重连、直线与折线、人工折点；移动节点保持关系 |
| 视口 | 普通滚轮滚动，Command+滚轮按指针缩放（非 Mac 支持 Ctrl），空格+左键拖动平移；−/+、100%、适应；10%～400%；视口变化不修改图稿内容 |
| 主题 | 纸白、松石绿、暖沙金、海湾蓝、靛青、蔷薇、陶土、青瓷、雾灰、高对比；无选区作用于全图，有选区作用于所选对象及组内内容，跳过锁定对象 |
| 颜色 | 填充、边框/连线、文字；颜色选择器与 #RRGGBB 输入，点击用色应用；最近 10 色持久化并直接显示在快捷栏；填充/边框可无色 |
| 样式效率 | 复制/粘贴外观，不改变文字、形状类型、ID、布局及连接；6 种对齐、2 种等间距，同一容器中选择至少 2/3 个节点 |
| 一键美化 | 消除可安全拉直的冗余连线折点；保留节点、语义、关系和障碍规避，不宣称自动重排任意图稿 |
| AI 会话 | 页面选择本机 CLI、修改范围、文字和单张截图；即时用户消息、阶段摘要、耗时、输出进度、取消、结果差异 |
| AI 模型 | Codex 沿用本机配置；Qoder 支持 Auto 与指定 7 个模型；客户端与模型位于输入框下方 |
| 候选预览 | 点击后立即出现独立大图窗口；加载、可见错误和重试；支持缩放、适应、返回与应用；图片实际载入后才允许应用 |
| 候选应用 | 应用前备份、检查文档身份和当前规范化内容，再检查最新 revision；整次应用一步撤销。缩放、字体规范化和编辑后撤销回原内容不误报过期 |
| 真实冲突 | 默认保留后续编辑；继续预览或下载候选，也可确认并备份后覆盖当前画布。共享编辑锁和服务器版本校验始终生效 |
| 查找与核对 | 按文字/ID 查找定位；原截图并排对照；疑点定位及确认，相关语义改变后恢复待核对 |
| 备份恢复 | 下载副本、授权直接写回、草稿恢复、命名版本、候选应用前备份；直接写回检测外部修改及切图竞态 |
| 导出 | PNG/SVG 整图或选区、PDF 单页整图；倍率、边距、背景；整图 PNG/SVG 可附带可编辑源文件 |
| 分发 | 分享源码启动包，Node.js 22.22+；首次安装依赖与 Chromium，后续本地启动；提供启动命令和 Mac start.command |

## 主使用流程

1. 安装启动服务。局域网成员首次填写用户名进入文件库；管理员在设置中配置服务器 CLI。打开共享文档后先取得编辑权。
2. 新建/打开图稿，或从示例开始。通过 AI 会话输入要求、选择范围，可上传/粘贴/拖入截图。
3. 发送时读取当前未保存画布和选区；立即显示消息，后续显示真实执行摘要。生成期间可继续编辑。
4. 生成完成后查看差异，打开大图预览。用户确认应用时先备份，再检查是否仍为同一份内容；真实冲突保留候选。
5. 用主题、快捷颜色、格式复制、对齐或常规属性面板调整；可一步撤销批量操作。
6. 保存 `.drawio`，再按用途导出 PNG/SVG/PDF。分享图片不等于保存源图稿。

外部 Skill 文件交换、CLI 校验/渲染继续兼容，但网页内会话不要求额外安装 Skill。

## 数据与限制

- 当前支持流程图、系统架构等基础图形表达；不承诺任意第三方 `.drawio` 全兼容。多页、复杂 UML/BPMN、时序语义、多人同时编辑合并、Mermaid 转换和外部 MCP 控制属于后续范围。
- 单文件 20 MiB、展开 XML 50 MiB、最多 1,000 个可见对象；图片和导出像素限制以 [技术设计](../design/TECHNICAL_DESIGN.md) 为准。
- AI 请求当前图稿最多 2 MiB；一张 PNG/JPEG 附件最多 8 MiB；共享模式一次执行一个任务，运行和排队共最多 8 个；任务归属浏览器身份。连续 5 分钟无输出或总计 20 分钟终止，结构校验失败最多修复 2 次。
- 最近 12 轮网页内存消息；服务内最近任务保留约 1 小时，可刷新接回。服务重启不保留会话/候选，应下载需要长期保留的候选。
- 服务器版本每图最多 50 个，保存在数据目录 SQLite；浏览器身份、文档与回收站跨重启保留。浏览器本地版本每图最多 20 个，全局约 40 MiB，超限淘汰最旧版本。草稿、版本、最近颜色依赖浏览器站点存储，不取代磁盘文件。
- AI 成功响应记录不是持续在线保证；输出校验通过也不代表图片识别和业务语义完全正确。

## 验收门槛

发布前运行 `npm run check`、`npm run docs:check` 和分享包独立解压启动验证。覆盖编辑/连线、撤销、文件往返、备份恢复、PNG/SVG/PDF、AI 会话和候选冲突、主题/颜色/排列及大图预览。真实 AI 能力单独实测，列明模型与平台。不得将模拟 CLI 测试称为真实模型验证，也不承诺不存在未发现的问题。

身份简化证据见 [v1.2.1 验证报告](../testing/V1_2_1_IDENTITY_REPORT.md)，原共享功能证据见 [v1.2 共享验证报告](../testing/V1_2_SHARED_REPORT.md)，原绘图能力见 [v1.1 验收报告](../testing/V1_1_REPORT.md)。
